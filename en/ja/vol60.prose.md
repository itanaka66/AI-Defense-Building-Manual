# はじめに

## 本書について

本書は「AI自律型サイバー防御システム 構築マニュアル」第4巻の第60部です。第59部で、API の認証を本番に入れました。ここでは、API のエラーの応答とログから、内部の情報や入力された値が漏れないかを点検します。

1. API のエラーの応答の作りを読み、処理されない例外で内部の情報が出ないかを試す
2. 入力の検証のエラー（`422`）の応答に、送られた値がそのまま入ることを見つけ、決まったメッセージに直す
3. Uvicorn のログ・journal・syslog の保存先と権限を点検する

## 本書の表記

- コマンドやプログラムは、構築時に実際に使用したものをそのまま掲載しています。改変していません。
- 実行先は、各手順の「実行先」に示します。
  - **VM 230**：ai-defense-manager（root）

> **実行先：VM 230**

# おわりに

第60部で、API のエラーの応答とログの権限を点検し、入力の検証のエラーから値が漏れる問題を直しました。

| 項目 | 結果 |
|---|---|
| エラーの応答 | すべて決まったメッセージ。処理されない例外は `500 Internal Server Error` だけ |
| `422` の応答 | `{"detail":"Invalid request"}` に統一（本番で確かめた） |
| ログ | journal は `640`・`2755`、syslog は `syslog:adm`・`640`。サービスのアカウントはログを読めない |
| 残り | journal の保存の期間・容量がはっきり決まっていない |

次の第61部では、journal の容量の上限を決め、ログの管理の全体を点検します。

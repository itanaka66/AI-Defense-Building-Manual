# はじめに

## 本書について

本書は「AI自律型サイバー防御システム 構築マニュアル」第4巻の第63部です。第62部で作った FSS の検証の鍵を、VM 230 の外の **Proxmox のホスト `pve` の `/root`**（root 専用）に移します。

1. 移す先の `pve` と、VM 230 からの経路を確かめる
2. `pve` の SSH のホストの鍵を、コンソールで見た値と照らし合わせてから、VM 230 に登録する
3. VM 230 に、`pve` へ移すためだけの SSH の鍵を作り、公開鍵を `pve` に制限付き（`restrict`）で登録する
4. 検証の鍵を移し、SHA-256 で一致を確かめる

SSH のホストの鍵の確認を無効にする方法は使いません。

## 本書の表記

- コマンドやプログラムは、構築時に実際に使用したものをそのまま掲載しています。改変していません。
- 実行先は、各手順の「実行先」に示します。
  - **VM 230**：ai-defense-manager（root）
  - **pve**：Proxmox のホスト（root）。Proxmox の画面のノード `pve` の Shell（コンソール）

> **注意：** VM 230 のコマンドは、プロンプトが `root@ai-defense-manager` であることを確かめてから実行します。`pve` で実行すると、`pve` 自身への接続の確認になってしまいます。一般のユーザー（`aidefense`）で実行すると、root 専用の鍵が読めずに失敗します。

# 第3章　移すための SSH の鍵

## 3.1　VM 230 で鍵を作る

VM 230 専用の Ed25519 の鍵を作ります。秘密の鍵は VM 230 の root 専用の場所に置き、表示も転送もしません。

> **実行先：VM 230**

⟦C5⟧

秘密の鍵は `/root/.ssh/id_ed25519_pve_fss`（`600`）、公開鍵は `/root/.ssh/id_ed25519_pve_fss.pub` です。

## 3.2　`pve` の `authorized_keys` の作り

> **実行先：pve**

⟦C6⟧

⟦C7⟧

`pve` の SSH は `PermitRootLogin yes`・`PubkeyAuthentication yes`・`AuthorizedKeysFile .ssh/authorized_keys` でしたが、`/root/.ssh/authorized_keys` は通常のファイルではなく、**`/etc/pve/priv/authorized_keys` へのシンボリックリンク**でした。Proxmox のクラスタのファイルシステム（pmxcfs）が管理するファイルです。

> **実行先：pve**

⟦C8⟧

`pve` は Corosync を使うクラスタではなく、1台の構成でした。`pve-cluster` は正常に動き、`/etc/pve` は pmxcfs でマウントされています。

## 3.3　公開鍵を登録する

リンク先の `/etc/pve/priv/authorized_keys` を直接指定して、公開鍵を `restrict`（ポートの転送や PTY などを制限）を付けて足します。既存の RSA の鍵は残します。

> **実行先：pve**

⟦C9⟧

> **注意：** スクリプトの `KEY_BLOB`・`KEY_LINE` は、構築したときの公開鍵です。自分の環境では、3.1 で作った `.pub` の中身に置き換えます。`/root/.ssh/authorized_keys` に書くつもりでほかの方法を使うと、pmxcfs の側に残らないことがありました。

書いた直後の読み戻し、公開鍵のフィンガープリントの一致、`/root/.ssh/authorized_keys` を通した読み戻し、既存の RSA の鍵が残っていること、をすべて確かめました。SSH の設定の変更・再起動はしていません。

## 3.4　認証を試す

root で実行します。

> **実行先：VM 230**

⟦C10⟧

`PVE_SSH_AUTH=PASS`、接続先は `pve`、ユーザーは UID `0` でした。

# 第4章　検証の鍵を移す

秘密の鍵ではなく、検証の鍵を移します。移したあと、権限・所有者・SHA-256 を照らし合わせ、中身は表示しません。

> **実行先：VM 230**

⟦C11⟧

| 確かめたこと | 結果 |
|---|---|
| `pve` への SSH の公開鍵の認証 | 成功 |
| 検証の鍵の転送 | 成功 |
| `pve` の側のファイル | `/root/fss-verification-key-20261124.txt`、`root:root`・`600` |
| SHA-256 | 一致 |
| VM 230 の側の元のファイル | 残している |

# おわりに

第63部で、FSS の検証の鍵を VM 230 の外（`pve` の `/root`）に保管しました。

| 項目 | 結果 |
|---|---|
| `pve` のホストの鍵 | コンソールの値と照らし合わせてから `known_hosts` に登録 |
| 移すための鍵 | VM 230 `/root/.ssh/id_ed25519_pve_fss`。`pve` の `/etc/pve/priv/authorized_keys` に `restrict` 付きで登録 |
| 検証の鍵 | `pve` `/root/fss-verification-key-20261124.txt`（`600`、SHA-256 一致） |
| まだのこと | journald に封印の鍵を読み込ませ、封印が始まることを確かめる |

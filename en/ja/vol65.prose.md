# はじめに

## 本書について

本書は「AI自律型サイバー防御システム 構築マニュアル」第4巻の第65部です。第64部で、VM 230 の journal の FSS の封印を動かし、VM 230 の中で確かめました。VM 230 が乗っ取られたときにも信用できるように、**VM 230 とは別のホスト**で確かめます。

1. 封印した journal をひとまとめにして（切り替えてアーカイブにし）、Proxmox のホスト `pve` に移す
2. `pve` の systemd 252 ではこの形の journal を検証できないので、検証専用の VM 240（Ubuntu 24.04、systemd 255）を作る
3. `pve` から VM 240 に、journal と検証の鍵を移し、VM 240 で暗号の上で確かめる
4. 作った VM 230・保管した `pve`・確かめた VM 240 の3か所で、ファイルが変わっていないことを確かめる

検証の鍵の中身は表示しません。

## 本書の表記

- コマンドやプログラムは、構築時に実際に使用したものをそのまま掲載しています。改変していません。
- 実行先は、各手順の「実行先」に示します。
  - **VM 230**：ai-defense-manager（root）
  - **pve**：Proxmox のホスト（root）
  - **VM 240**：fss-verification（`192.168.0.222`、root。一般のユーザーでログインしたときは `sudo -i` で root になる）

# 第1章　封印した journal を `pve` に移す

## 1.1　検証用のアーカイブを作る

動いている journal をそのまま写すと、写している間にログが足されることがあります。journal を切り替えて、封印したアーカイブを作ります。ログの削除・サービスの再起動・鍵の変更はしません。

> **実行先：VM 230**

⟦C0⟧

アーカイブは `ARCHIVED`、`SEALED SEALED_CONTINUOUS`、`Tag objects` 9、8,388,608 バイトでした。

## 1.2　`pve` に移す

> **実行先：VM 230**

⟦C1⟧

転送は成功し、VM 230 と `pve` で SHA-256 が一致しました。

## 1.3　`pve` では検証できない

`pve` の systemd は 252.39 で、このアーカイブのヘッダーを `SEALED ???` と表示し、検証は次のように止まりました。

⟦C2⟧

VM 230 の systemd 255.4 では、同じアーカイブの検証は次のとおり成功します。

⟦C3⟧

journal の鍵が間違っているのでも、ファイルが壊れているのでもなく、systemd のバージョンの違いで、252 が新しい形を読めないためです。そこで、systemd 255 の検証専用の VM を作ります。

# 第3章　VM 240 に移して確かめる

## 3.1　`pve` の側の確認

> **実行先：pve**

⟦C12⟧

転送の元の2つのファイル（journal・検証の鍵）があり、journal の SHA-256 は前の転送のときと同じでした。VM 240 のホストの鍵も、控えたフィンガープリントと一致しました。

## 3.2　移す

照らし合わせたホストの鍵を使って、VM 240 のユーザー `ag` の `/home/ag/` に移します。パスワードを聞かれたら、VM 240 の `ag` のパスワードを入力します（チャットやメモには書きません）。

> **実行先：pve**

⟦C13⟧

2つのファイルとも終了コード `0` で移りました。

## 3.3　VM 240 で一致を確かめる

> **実行先：VM 240**

⟦C14⟧

journal・検証の鍵とも、`pve` の元のファイルと SHA-256 が一致しました（journal 8MiB、鍵44バイト）。

## 3.4　root 専用の場所に置く

> **実行先：VM 240**

⟦C15⟧

journal・検証の鍵とも `root:root`・`600` で `/root/` に置き、ハッシュは一致しました。`/home/ag/` の元のファイルは残しています。

## 3.5　VM 240 で確かめる

> **実行先：VM 240**

⟦C16⟧

| 確かめたこと | 結果 |
|---|---|
| 確かめたホスト | VM 240 `192.168.0.222`（systemd 255.4） |
| アーカイブ | `ARCHIVED`、`SEALED`・`SEALED_CONTINUOUS`、`Tag objects` 9 |
| 確かめた期間 | 2026-11-24 01:43:04〜02:00:00 UTC |
| `journalctl --verify --verify-key` | `PASS` |

**VM 230 とは別のホストで、VM 230 から移したアーカイブの FSS の検証に成功しました。**

# おわりに

第65部で、FSS で封印した VM 230 の journal を、別のホスト（VM 240）で確かめました。

| 項目 | 結果 |
|---|---|
| 検証用のアーカイブ | VM 230 → `pve` → VM 240、すべての場所で SHA-256 一致 |

| VM 240 | Ubuntu 24.04.5・systemd 255.4、2 vCPU・4GiB・32GiB、`192.168.0.222` |
| 別のホストでの検証 | 合格 |
